## 1. LTEE Reproductions (V134) — Ecosystem Critical Path

### B2: Wiser 2013 Power-Law Fitness Dynamics (Exp 036)

**What**: Reproduced jackknife + AIC/BIC model selection across power-law, hyperbolic, and logarithmic fitness models. Validates that power-law `w = 1 + A·t^b` wins by information criteria on LTEE-scale data.

**New Rust infrastructure**:
- `stats::regression::fit_power_law` — offset power-law `w = 1 + A·t^b` via log-linearized OLS
- `stats::regression::fit_hyperbolic` — Michaelis-Menten offset `w = 1 + at/(1+bt)`
- `stats::model_selection` — `aic()`, `bic()`, `rss()`, `compare_models()`
- `fit_all` expanded to 6 models (was 4)

**Validation**: Python 9/9 PASS, Rust 10/10 PASS (two-phase: noiseless model selection + noisy jackknife variance).

**Output**: `control/ltee_fitness_dynamics/expected_values.json` → `lithoSpore` module 1 (`ltee-fitness`).

**Unblocks**: `lithoSpore` module 1 AND Pillar 4 exit gate.

### B1: Barrick 2009 Neutral Mutation Accumulation (Exp 037)

**What**: Validates neutral fixation theory (Kimura `P_fix = 1/N`), molecular clock linearity, and drift dominance at `|s| = 1/N`.

**Validation**: Python 8/8 PASS, Rust 8/8 PASS.

**Output**: `control/ltee_neutral_mutation/expected_values.json` → `lithoSpore` module 2 (`ltee-mutation`).

**Unblocks**: `lithoSpore` module 2.

### Key Finding: PRNG Divergence + Linearization Bias

Python (`numpy.random.default_rng`, PCG64) and Rust (`Xorshift64`) produce different noise streams for identical seeds. Additionally, log-linearized OLS introduces systematic bias on noisy power-law data (exponent shifts ~0.03 vs true value). The Rust validation addresses this with a two-phase design: Phase 1 validates model selection on noiseless data generated by the *same functional form* as the fitter, Phase 2 validates jackknife variance on noisy per-population data.

**Pattern for other springs**: If your LTEE reproduction involves nonlinear fitting, validate model selection logic separately from noise tolerance.
